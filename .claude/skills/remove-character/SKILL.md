# ลบตัวละครออกจากเกม ECHO

ไม่ใช่แค่ลบ `characters/<id>.js` — ตัวละครหนึ่งตัวแทรกตัวอยู่ทั่ว engine, ฝั่ง client,
ทะเบียนสถานะกลาง, เสียง/CSS และเทสต์ ถ้าไล่ไม่ครบ
เกมจะพังตอนรันจริงแบบเงียบๆ (`CHAR_HOOKS.<id> is undefined`) ไม่ใช่ตอน build

> ตัวละครที่มีตอนนี้: `muimi` และ `oberon_summer` · เกมเป็นกระดานเดินได้แล้ว ([GRID_PLAN.md](../../../GRID_PLAN.md)) —
> จุดเสียบที่ต้องถอนคือคู่กลับของสกิล `add-character` (อ่านตาราง "จุดเสียบใน server/" ที่นั่นประกอบ)

## ไล่ให้ครบก่อนแตะอะไร

```bash
grep -rn "<id>\|<Id>\|<ID>\|<prefix>" --include=*.js --include=*.jsx --include=*.css . \
  | grep -v node_modules | grep -v client/dist | grep -v .claude/worktrees
```

ต้องค้น **ทุกรูปแบบตัวพิมพ์** เพราะโค้ดใช้ปนกัน: `muimi` (id/ฮุค) · `Muimi` (ชื่อคอมโพเนนต์ เช่น `MuimiLoseBadge`)
· `MUIMI` (ค่าคงที่) และ **คำนำหน้าย่อของตัวละคร** ที่ไม่มีชื่อเต็มอยู่เลย — โอเบรอน (ฤดูร้อน) ใช้ `obs`
(`obsVeil`/`obsDream`/`obsLark` ใน `STATUS_INFO` ของ Game.jsx และในเทสต์รวม) grep แค่ `oberon` จะไม่เจอ
ดูคำนำหน้าจากคีย์ `statuses.*` และฟิลด์ใน `resetCombat` ของไฟล์ตัวละครก่อน
ไฟล์เสียงบางไฟล์สะกดเพี้ยน (`mumi_normal_hit.mp3`) — ค้นใน `client/src/audio.js` ด้วยตาด้วย
**อ่านผลให้ครบก่อนลงมือ** — รายการนี้คือเช็คลิสต์ ไม่ใช่แค่ตัวเลข

⚠️ **ระวังชื่อชนกัน** — คำนำหน้าสั้นๆ อาจชนกับของกลาง (เช่น `obs` กับคำอื่นที่ขึ้นต้นเหมือนกัน) ต้องอ่านคอมเมนต์ข้างๆ ก่อนลบทุกครั้ง

## ลำดับที่ปลอดภัย

ไล่จาก "ปลายน้ำ" เข้าหา "ต้นน้ำ" แล้วเช็ค syntax ทุกก้าว — ถ้าลบ `characters/<id>.js`
ตั้งแต่แรก ไฟล์อื่นจะพังหมดจนหาจุดที่เหลือไม่เจอ

1. `server/` (จุดเยอะสุด — `grep -rn "<id>" server`) → `node -e "require('./server.js')"`
2. `client/src/screens/Game.jsx` (+ `client/src/board/` ถ้ามีอะไรเฉพาะตัว) → `npx eslint client/src/screens/Game.jsx`
3. `characters.js` · `characters/_transforms.js` · `characters/index.js`
4. ไฟล์เล็ก: `client/src/audio.js` · `arena.css` · `CharacterSelect.jsx` (`order`) · `permanentStatus.js` · หน้าพรีวิว (`hud/GamePreview.jsx`, `hud/HudPreview.jsx`, `board/BoardPreview.jsx`)
5. ค่อยลบ `characters/<id>.js` และ `tests/characters/<id>.test.js`
6. เทสต์ที่เหลือซึ่งอ้างถึงเขา (`computeAttackBase.test.js`, `duplicate-safety.test.js`, `skill-area.test.js`, `action.test.js`
   และเทสต์ระบบที่ใช้เขาเป็นตัวละครทดสอบ — เปลี่ยนเป็น `characterId: "dummy"`)
7. `npm test` 2-3 รอบ · `npx eslint` · `cd client && npm run build`

## จุดที่ต้องถอนใน server/

ใช้เป็นเช็คลิสต์คู่กับผล grep — ทุกบรรทัดที่ `add-character` บอกให้ "เสียบ" คือบรรทัดที่ต้อง "ถอน"

| หมวด | สิ่งที่ต้องถอน |
|---|---|
| ค่าคงที่/รูป | `IMG`/`SOUND` ของเขาที่ไฟล์อื่น import ไป (เช่น `require("./muimi").IMG` ใน `_transforms.js`) |
| สถานะแมตช์ (`server/match.js`) | ธงสนามของเขา (ถ้ามี) + ทุกที่ที่ reset |
| ฮุคที่ server เรียกเจาะจง | `combat.resetCombat` · `newPlayerRecord` (`socket.js`) · ลูปต่อผู้เล่นใน `dealRound` (`phases/draw.js`) · `endTurn` (ในลูปลดเทิร์น + หลังลูป) · `strike` / `computeAttackBase` / `attackSoundOf` (`phases/attack.js`) · `displayImg` / `activeSkillMusic` / `buildStateFor` (`view.js`) |
| จุดเสียบของระบบกระดาน | `beginOrder` / `nextActor` / `finishActor` / `moveTo` (`phases/action.js`) ถ้าเขาเสียบไว้ |
| ด่านกลางเกม | `useSkill` (`skills.js`) · `useInventoryItem` / `buyShopItem` (`shop.js`) · `hit` / `lock` (`phases/draw.js`) |
| ฟังก์ชันเฉพาะตัว | ฟังก์ชันระดับไฟล์ที่เขียนไว้ให้เขาคนเดียว + ที่ export ให้เทสต์ (`engine.*` ใน `engine.js`) |
| ก้อน state | ฟิลด์ใน `buildStateFor` (เช่น `muimiEmergencyUses`, `muimiUltCd`) + ธงฉากหลัง/เพลงสนาม |

ฮุคกลาง (`canUseSkill` · `applyInstantSkill` · `skipsTurnQuota` · `skillLocks` · `damageBonus` · `adjustIncomingDamage` ฯลฯ)
อยู่ในไฟล์ตัวละครเอง หายไปพร้อมไฟล์ — ไม่ต้องแก้ server/ ส่วนนั้น
ข้อมูล `mov` / `range` / `area` อยู่ใน `characters.js` หายไปพร้อมรายการตัวละคร

## เส้นแบ่ง: อะไรลบ อะไรเก็บ

นี่คือจุดที่ตัดสินใจผิดแล้วเสียหายทั้งสองทาง — ลบเกินทำให้ตัวละครอื่นพัง ลบขาดทิ้งโค้ดตายไว้

**ลบ** — สิ่งที่ตายไปพร้อมเขา:
- สถานะที่ **มีแต่เขาแจกได้** (เช่น `obsVeil`/`obsDream`/`obsLark` ของโอเบรอน · `muimiTower`/`muimiRusty` ของมุยมิ) รวมถึงชื่อใน
  `BUFF_KEYS` / `SOFT_DEBUFF_STEP` / `NO_TICK_STATUS` / `client/src/data/permanentStatus.js`
  และป้ายใน `STATUS_INFO` ของ `Game.jsx`
- คัตซีนทุกคีย์ใน `_transforms.js` · เสียง/เพลงใน `audio.js` · CSS เฉพาะตัวของเขา
- ตัวแปรที่ destructure แล้วไม่มีใครผลิตอีก · คอมโพเนนต์/ป้ายบน HUD ของเขา

**เก็บ** — ของกลางที่บังเอิญเขาเป็นคนใช้:
- สถานะที่ประกาศเป็น **Universal** และมี API ของตัวเองใน `_universal_status.js`
  (`curse` มี `applyCurse`/`tickCurseOnSkill` เหมือน `poison`/`shock`/`mend`) — เป็นคำศัพท์ร่วม
  ที่ตัวละครหน้าหยิบไปใช้ได้ ไม่ใช่เอฟเฟกต์ส่วนตัว
- ระบบแกนที่เขาแค่ไป**เกาะ** ไม่ได้เป็นเจ้าของ: วงจรกลางวัน/กลางคืน (`isNightRound`) — **ห้ามลบโค้ดวัน/คืน** (GRID_PLAN §8)
  · ระบบกระดาน (`server/board.js`, `phases/action.js`, `resolveArea`, `skillStrike`, `hasActed`) · Mark 42 · ปืน GUTS · การเดินทาง 7 ภูมิภาค
- ของที่ตัวละครอื่นยังอ่านอยู่ — `engine.skillStrike` / `engine.hasActed` เปิดไว้ให้ทุกตัวละคร แม้ตอนนี้จะมีคนใช้คนเดียว
- โฟลเดอร์สื่อ `overload_force` (`server/mediaDirs.js`) เป็นแค่ชื่อโฟลเดอร์ที่เก็บเพลงท่าไม้ตายมุยมิ —
  **ระบบ Overload Force ถูกถอดออกไปแล้ว** ไม่ต้องตามหาหรือลบอะไรของระบบนั้น (ถ้าลบมุยมิ เพลงนั้นตายตามได้)

**ห้ามลบเด็ดขาด**: `client/public/characters/<id>/` — อยู่ใน `.gitignore` ลบแล้ว git กู้ไม่ได้
ปล่อยไว้ไม่เสียอะไร บอกผู้ใช้ว่าปล่อยไว้แล้วให้เขาตัดสินใจเอง (บน R2 ก็เช่นกัน)

## โค้ดระบบเก่าที่ grep แล้วอาจเจอ — อย่าสับสน

เกมย้ายจากวงจร "ผู้ชนะการจั่วได้ตี" มาเป็นกระดานแล้ว แต่ `client/src/screens/Game.jsx` บางส่วนยังเป็นโค้ดเก่าที่รอถูกแทน
(เฟส `SUMMARY` / `ATTACK`, `state.attackerId`, ที่นั่งรอบสนาม) — ถ้าบล็อกของตัวละครอยู่ในโค้ดพวกนี้ ลบแค่ส่วนของเขา
อย่าถือโอกาสรื้อโค้ดเก่าทั้งก้อนในงานลบตัวละคร (คนอื่นกำลังทำขั้นของ GRID_PLAN อยู่)
ฝั่ง server ไม่มีเฟส `SUMMARY`/`ATTACK` แล้ว (`phases/summary.js` เหลือแค่ `resolveRound` → `afterResolve` → `action.beginOrder`)

## กับดักตอนลบ

**1. คอมเมนต์ไทยยาวๆ ลอกมาเทียบไม่เคยตรง** — เครื่องหมาย `—` vs `-`, ช่องว่างซ้อน, คำที่จำผิด
ไปหนึ่งคำ ทำให้ `assert s.count(a) == 1` ล้มเรื่อยๆ **อ้างจากบรรทัดโค้ดอย่างเดียว** แล้วค่อยไล่ถอย
ขึ้นไปกินคอมเมนต์เหนือมัน:

```python
i = next(k for k, ln in enumerate(lines) if 'CHAR_HOOKS.x.foo(' in ln)
start = i
while lines[start - 1].lstrip().startswith("//"):
    start -= 1
del lines[start:i + 1]
```

**2. บล็อก JSX ต้องปิดด้วยย่อหน้าเดียวกับบรรทัดเปิด** — `{xSel && (` ... `)}` ซ้อนกันหลายชั้น
ถ้าจับ `)}` ตัวแรกที่เจอจะตัดผิดที่แล้วเหลือ `</div>` ลอย เทียบ indent ของบรรทัดเปิดเสมอ:

```python
indent = len(lines[i]) - len(lines[i].lstrip())
j = next(k for k in range(i + 1, len(lines))
         if lines[k].strip() == ")}" and (len(lines[k]) - len(lines[k].lstrip())) == indent)
```

**3. Game.jsx มีหลายชุด** (กระดานมือถือ + จอคอม + HUD) — ป้าย/โมดัล/แบนเนอร์ของตัวละครมักมีมากกว่าหนึ่งที่
(เช่น `MuimiLoseBadge` ถูกเรียกสองจุด) ลบที่เดียวแล้ว grep จะยังเหลือ · โค้ดมือถือลบได้เฉพาะส่วนของตัวละคร (CLAUDE.md: ไม่ทำมือถือแต่ไม่ต้องรื้อ)

**4. บล็อกที่มีหลายบรรทัดต้องตัดให้ครบทั้งก้อน** — ตัดแค่บรรทัดแรกของ `if (k) { ... }` เหลือ
ตัวข้างในลอยอยู่นอกฟังก์ชัน `eslint` จะฟ้อง `'return' outside of function` ซึ่ง**ชี้ผิดที่**
ให้ดูบรรทัดที่มันฟ้องแล้วไล่ขึ้นไปหาก้อนที่เพิ่งลบ

**5. คอมเมนต์ท้ายบรรทัดอาจมีของตัวละครอื่นติดมาด้วย** — เคยมีคอมเมนต์ของหลายตัวละครต่อกันอยู่บรรทัดเดียว
ลบทั้งบรรทัดจะพาคำอธิบายของคนอื่นหายไปด้วย อ่านคอมเมนต์ก่อนลบเสมอ

**6. สำรองไฟล์ก่อนรันสคริปต์ลบ** — `git stash` หรือ commit ก่อนทุกครั้ง สคริปต์ที่ assert
กลางทางจะทิ้งไฟล์ไว้ครึ่งๆ กลางๆ ถ้าเขียนแบบ write ทีละจุด (เขียนแบบสะสมใน memory แล้ว
write ครั้งเดียวตอนจบจะปลอดภัยกว่า)

**7. เทสต์ที่ตายตามต้องลบด้วย** — ไม่ใช่แค่ `tests/characters/<id>.test.js` แต่รวม assert
ที่ฝังชื่อเขาไว้ในเทสต์รวม (`computeAttackBase.test.js` มีเทสต์โบนัสโจมตีของตัวละคร ·
`skill-area.test.js` ตรวจ `area` ของทุกตัว · `duplicate-safety.test.js`) — ถ้าเหลือตัวละครเดียว
เทสต์ที่ต้องการสองตัวละครต้องเปลี่ยนไปใช้ `dummy` ไม่ใช่ลบทิ้ง

## บทเรียนจากการตรวจบัค (ใช้ได้ทั้งตอนลบและตอนเพิ่ม)

ตัวอย่างในหัวข้อนี้บางชื่อมาจากตัวละคร/ระบบที่ลบไปแล้ว — เก็บไว้เป็นบทเรียน ไม่ใช่ชื่อที่ต้อง grep หา

บัคที่เจอซ้ำๆ ในโค้ดเบสนี้มาจากรากเดียวกัน: **แกนร่วมที่ตัวละครหลายตัวใช้**

**ฮุคร่วมถูกเรียกซ้ำ** — ถ้า `server/` เรียก `CHAR_HOOKS.a.onRoundStartTick(...)` และ
`CHAR_HOOKS.b.onRoundStartTick(...)` กับผู้เล่น**ทุกคน** แล้วทั้งสองไฟล์ส่งต่อให้แกนร่วมที่
ด่านเป็น "เป็นตระกูลนี้ไหม" ผลจะถูกคิดสองรอบ (เคยมีท่ากินแต้ม 4/เทิร์นแทน 2)
→ **ทุกฮุคต้องมีด่าน id ตัวเองก่อนส่งต่อให้แกนร่วมเสมอ** และเทสต์ควรเรียกฮุคของ**ทุกตัวในตระกูล**
เหมือนที่ server ทำจริง ไม่ใช่เรียกแค่ตัวที่กำลังเทสต์

**ล้างด้วยสคริปต์แล้วต้องตรวจเศษที่ค้าง** (บทเรียนจากการย้าย repo 2026-10 ที่ลบ 56 ตัวรวด) —
สคริปต์ที่พับเงื่อนไข `characterId === "<id>"` ทิ้งไว้แบบนี้ ต้อง grep หาแล้วเก็บกวาดเอง:
`&& true` · `|| false` · `const x = undefined;` · `([]).length` · `null?.` · `{undefined}` ใน JSX · ฟังก์ชันที่เหลือแค่ `return null;`
และระวังสคริปต์ตัดฟิลด์ที่ชื่อชนกับของกลาง — เคยตัด `cracks` (ชื่อชนกับฟิลด์ของตัวละครเก่า) ออกจาก
`journey/scenes.jsx` จนฉากภูมิภาค VII พังตอนรัน · หลังลบต้องเปิดหน้าพรีวิว `?hud=1&game=1` และ `?board=1` ดูด้วย ไม่ใช่แค่ build ผ่าน

**สถานะของสนามต้องตัดสินจากสนาม** — เคยมีท่าหยุดเวลาที่ดูจากคนที่เพิ่งกดปุ่ม
พอคนหนึ่งปิด เวลาเดินต่อทั้งที่อีกคนยังแช่อยู่ → อะไรที่เป็นกติกาสนาม ให้ถามสนาม (ทุกคนที่ยังเปิดท่าอยู่)
ไม่ใช่ถามผู้เล่นคนเดียว

**`triggerCutscene` เล่นคลิปเต็มครั้งเดียวต่อเกม** — เหตุการณ์ที่ควรเห็นทุกครั้ง (สลับร่าง
ตามเวลา, เปิดท่าที่กดซ้ำได้) ต้องใช้ `queueCutscene` ไม่งั้นครั้งที่สองเป็นการ์ดเล็กๆ
แล้วผู้เล่นจะรายงานว่า "ไม่เปลี่ยนร่าง" (มุยมิใช้ `queueCutscene` สลับคลิปเต็ม/คลิปสั้น)

**ทางที่ `return` ก่อนถึงปลายทาง** — ด่านหลบหลีก/เนตรมณะ/ป่าพลาดเป้าใน `strike()` return ตั้งแต่ต้น
ไม่ผ่านโค้ดท้ายฟังก์ชัน อะไรที่ต้องเกิด "ทุกกรณี" ให้แขวนไว้ที่ปลายทางร่วม: จบตา = `finishActor()`
(ทุกทาง: ตี/รอ/หมดเวลา) · จบเทิร์น = `endTurn()`

**`clip-path` ตัดลูกหลานทุกตัว** — ไม่สนใจ `z-index` หรือ `overflow` ป้ายที่วางไว้ `-top-2`
บนการ์ดที่มี clip-path จะหายทั้งใบ เหลือแต่เงาที่เล็ดลอดออกมา ป้ายที่ลอยพ้นขอบต้องอยู่**นอก**
element ที่ถูก clip

**โค้ดตายที่อ้างฟังก์ชันไม่มีจริง** — เคยมีฟังก์ชันใน engine เรียกชื่อฮุคที่สะกดผิด (เอกพจน์/พหูพจน์)
ไม่ระเบิดเพราะไม่มีใครเรียก แต่เป็นกับระเบิดรอคนต่อสาย → ตอน grep เจอชื่อฮุค
ให้เช็คด้วยว่า**มีจริงไหม** ไม่ใช่แค่ว่าถูกเรียกไหม

## เขียนคำอธิบายให้ผู้ใช้

ผู้ใช้เป็นคนไทย ใช้ภาษาไทย และบอกให้ครบสามอย่างเสมอ: **ลบอะไรไป** · **อะไรเก็บไว้และทำไม** ·
**อะไรที่ไม่ได้แตะ** (โดยเฉพาะไฟล์สื่อที่ gitignore ไว้) — การเก็บของกลางไว้ไม่ใช่ความขี้เกียจ
แต่ต้องบอกเหตุผล ไม่งั้นดูเหมือนลบไม่ครบ
