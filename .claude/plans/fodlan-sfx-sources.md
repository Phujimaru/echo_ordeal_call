## ขั้นตอน
- **One-shot** (สูตรเดียวกับ emiya-sfx): ตัดช่วง → วางเลเยอร์ตามเวลา (at หรือ `pk` = จัดให้จุดดังสุดของเลเยอร์ตรงเวลานั้น) พร้อม gain/กรอง → ตัดความเงียบหัวไฟล์ของมิกซ์ (จุดแรกที่ดังเกิน −30 dB จากพีค − 4 ms; บางคีย์ที่ค่อยๆ ดังใช้ −40/−45) → fade-in 3 ms / fade-out cosine → (บางคีย์ alimiter ลดพีคแหลม) → ปรับดังแบบ gain ล้วนไป −16 LUFS integrated เพดาน sample peak −3.5 dBFS ก่อนเข้ารหัส (หลัง mp3 ≤ −3) และไม่เกิน −15.5 LUFS → mp3 160 kbps 44.1 kHz stereo
- **ลูป** (amb_* / wx_rain / wx_miasma / wx_blizzard / campfire): แต่ละเลเยอร์พื้นหลังตัดจาก "ช่วงค้นหา" ที่ offset ซึ่งหน้าต่างครอสเฟดทั้งสองฝั่งไม่มีเสียงกระแทกและระดับใกล้กัน → ครอสเฟดแบบ equal-power เอาหาง (P..P+X) ทับหัว (0..X) ให้วนต่อเนื่อง → ถ้าต้นฉบับสั้นกว่าลูป วนซ้ำ k รอบ (คาบ = L/k) → ปรับ RMS แต่ละเลเยอร์เป็น −20 dBFS + gain → วาง "อีเวนต์" (กา, หยดน้ำ, ดาบไกลๆ…) ในลูป ส่วนเกินท้ายลูปวนไปต่อหัว → หมุนจุดเริ่มไฟล์ (ลูปเป็นวงกลม) ไปที่ที่ระดับ 0.5 s ซ้าย-ขวาเท่ากัน ไม่มีเสียงเด่น และ ±25 ms หา sample ที่คลื่นใกล้ 0 (ลดเสียงรบกวนของเฟรม mp3 ที่ขอบไฟล์) → ปรับดัง −22 LUFS (ลูปที่ใช้ limiter: limit 3 ชุดต่อกันแล้วเก็บชุดกลาง สถานะ limiter จึงต่อเนื่องข้ามรอยต่อ) · ไม่มี fade ไม่มีการตัดหัว
- ตรวจรอยต่อลูปหลังถอด mp3: ต่อไฟล์กับตัวเอง วัดความโค้ง (diff อันดับ 2) ±5 ms รอบรอยต่อเทียบเปอร์เซ็นไทล์ 99.9 ของทั้งไฟล์ → ทุกลูป 0.16–0.92 (ไม่โดดกว่าเนื้อเสียงปกติ) · ระดับ 0.5 s แรก/ท้ายต่างกัน ≤ 0.4 dB · ความยาวหลังถอดตรงเป๊ะ (LAME gapless tag)
