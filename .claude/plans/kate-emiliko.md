# เคท & เอมิลิโกะ — แผนงาน (worktree `.claude/worktrees/kate-emiliko`, branch `kate-emiliko`)

ที่มา: Shadows House · คำตอบผู้ใช้ทั้งหมดอยู่ใน memory `kate-emiliko-spec.md`

## โครงสร้าง (ระบบคู่ — `server/duo.js`)
- ผู้เล่นเลือก `kate` (ชื่อบนการ์ดเลือก "เคท & เอมิลิโกะ") → ระเบียนผู้เล่นปกติ = เคท
- เริ่มแมตช์ (`lobby.startMatch`) สร้างระเบียนคู่ `<id>~emi` (`characterId: "emiliko"`, `duoOf: ownerId`) · ลบตอนกลับห้องรอ
- ใช้ร่วม (getter/setter บนระเบียนคู่ชี้ไปเจ้าของ): `skillPoints` `gold` `inventory` `cards` `busted` `result`? (ไม่) — ไพ่/ลำดับเดินใช้ของเจ้าของ
- ระเบียนคู่ไม่จั่วไพ่ (`locked` ตลอด) · ไม่อยู่ใน turnOrder · ไม่ได้ socket
- `sameTeam(kate, emi)` = true เสมอ (ffa ด้วย) → ตีกันเองไม่ได้ · จบเกมนับเป็นฝ่ายเดียว
- ตกรอบเมื่อตายทั้งคู่ · ตัวที่ตาย: `corpse = {x,y}` ยังขวางช่อง (เดินผ่านได้ หยุดไม่ได้ · ผลัก/ไถลชน)
- ตาเดิน: เจ้าของถึงคิว → คุมตัวที่ยังอยู่ (เคทก่อน) · `match.duo = { ownerId, cur, acts: {id: action}, done: {id}, deadline }`
  - สลับ (กระจกเงา): เก็บ action ของตัวเดิม → ตัวเดิมที่เดินแล้วล็อกการเดิน · สลับไปตัวที่ done ไม่ได้
  - ตี/รอ = ตัวนั้น done → เหลืออีกตัว = สลับไปให้อัตโนมัติ · ครบทั้งคู่/หมดเวลา = จบตา
  - เวลา 1 นาทีรวม (deadline) — ฉากตีตัดเวลาเดินแล้วตั้งต่อด้วยเวลาที่เหลือ
- จบเทิร์น: แต้มสกิล +2 (ครั้งเดียวต่อคู่ + โบนัสกลางวัน 1 ครั้ง) · เหรียญครั้งเดียว · ไพ่สี (แดง/เขียว/น้ำเงิน/เหลือง) ลงทั้งคู่ (เหลือง = แต้มรวม ครั้งเดียว)
- เปลี่ยนภูมิภาค: เอมิลิโกะเกิดติดเคท (ศพด้วย)
- Mark 42: ใส่ได้ทีละตัว (ระเบียนแยกอยู่แล้ว)

## สกิล
- พื้นฐาน (ทั้งสองตัว): กระจกเงา 0 แต้ม สลับตัว (ไม่กินโควตา ไม่ล็อกเดิน) · อีกตัวตาย → ปุ่มกลายเป็น "ตื่นขึ้นอีกครั้ง" 6 แต้ม (ศพในระยะ 4 · ฟื้นเลือด 3 เกราะ 0 · ไม่จำกัด)
- เอมิลิโกะ: เดิน 3 (ในระบำเขม่า 4) · รอง = เลือกอาวุธ (0 แต้ม ไม่กินโควตา ไม่ล็อกเดิน) ไม้ถูพื้น/แจกัน/เครื่องดูดฝุ่น/ดาบเขม่า(ถ้าได้รับ)
  - ไม้ถูพื้น: เดินลงพื้นเปียก = ไถลสุดแนว · ชนเป้า 2 (บัฟไม่ได้ ไม่กระเด็น ไม่จบตา) · แนวที่ไถลแห้ง
  - แจกัน: ตีปกติผลักเป้า 3 ช่อง (ชน = −1) · ทางที่ถูกผลักเป็นพื้นเปียก (ถาวร · ทุกคนไถล)
  - เครื่องดูดฝุ่น: ระยะตี [1,3] · ดาเมจ = ระยะห่าง (บัฟไม่ได้) · ดูดเข้าประชิด
  - ดาบเขม่า: พลังโจมตี +2
  - ติดตัว: ตี/รอ แล้วเดินต่อได้ 2 (ทำอย่างอื่นไม่ได้ · เหยียบพื้นเปียกไถลเกินได้)
  - ท่าไม้ตาย ร่าเริงสุดๆ 6 แต้ม: แนว 4×3 ตามอาวุธ (ไม้ถูพื้น = พุ่ง 4 + ผลักทุกคนไปสุดปลาย + 2 + ชนเพิ่ม + เปียกตามทางพุ่ง)
- เคท: เดิน 4 (ในระบำเขม่า 6) · รอง = เลือกใช้: แส้เขม่า 2 (ระยะ 3: เอมิลิโกะ = ดึงมาติด · ศัตรู = เคทพุ่งไปติด + 1) · ดาบเขม่า 0 (ถือ/ให้/เรียกคืน ระยะรอบตัว 4 · เคทถือ +1) · ปีกเขม่า 4 (บิน 4 ตามทิศ ข้ามทุกอย่าง ลงไม่ได้ = บินต่อ · พาเอมิลิโกะที่ติดตัวไปด้วย)
  - ท่าไม้ตาย ระบำเขม่า 6: เลือกช่องกลางในระยะ 4 · 8×8 (−4..+3) 3 เทิร์น · ศัตรูข้างใน −1 ทันทีและทุกเทิร์น · ขังทุกคน (เคท/เอมิลิโกะออกได้) · คนนอกเข้าได้ · นอก/ในมองไม่เห็นกัน · สู้กันข้างในไม่โผล่ · สกิลพื้นที่จากนอกโดนได้
  - ติดตัว: ในระบำเขม่า ตีปกติ → เป้า "มืดบอด" 1 เทิร์น (หมากทุกตัวยกเว้นตัวเองเป็นสีขาว ไม่มีชื่อ/ภาพ/ลำดับ)
