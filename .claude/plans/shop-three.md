## 2. หน้าตาร้าน (แต่ละร้านคนละแบบ — ไม่ใช่ตาราง)

ทุกร้านใช้เวทีเต็มจอ 1920 × 1080 แบบเดียวกับกระเป๋า · พื้นขาว ORDEAL CALL + ลายประจำร้าน · ซื้อแล้วของ "บิน" เข้าไอคอนกระเป๋ามุมจอ
ส่วนที่ใช้ร่วมทุกร้าน: แถบบน (ตราร้าน · ชื่อร้าน · "เหลือ N เทิร์น" · เหรียญ · ✕) และแถบกระเป๋า 5 ช่องด้านล่าง (เห็นทันทีว่าที่ว่างพอไหม)

### 2.1 ร้านยาเจริญชัย (ร้านไอเทม) — "ชั้นวางขวดยา"
- ฉากหลัง: ตู้ไม้ขาวมีชั้นวาง 3 ชั้น = 3 หมวด (ช่วงจั่ว / ตาเดิน / พิเศษ) · ของแต่ละชิ้นเป็น **ขวด/วัตถุตั้งบนชั้น** มีป้ายราคาห้อยใต้ขวด
- จำนวนคงเหลือ = ขวดซ้อนกันด้านหลัง (เห็นเป็นเงาจางตามจำนวน) + เลข "×3"
- ชี้ = ขวดยกขึ้นเรืองแสง · คลิก = ขวดลอยมาวางบน **เคาน์เตอร์** ด้านล่าง (แผงรายละเอียด: รูปใหญ่ · ชื่อ · ผลย่อ · ราคา · ปุ่มซื้อ)
- ซื้อ = ขวดหมุนเข้าถุง + ป้ายราคาพลิก · หมด = ชั้นว่างมีฝุ่นประกาย + ป้าย "หมด"

### 2.2 โรงช่างลุงเริง (ร้านอุปกรณ์) — "แผงเครื่องมือโรงช่าง"
- ฉากหลัง: ผนังแผ่นเหล็กรูพรุนสีเงิน (pegboard) · อุปกรณ์แขวนบนตะขอเป็นช่องใหญ่ · มีเฟือง/สกรูประดับ
- ช่องที่เลือก = ไฟสปอตไลต์ส่อง + เฟืองหมุน · แผงรายละเอียดเป็น **โต๊ะทั่ง** ด้านขวา
- ของถาวร (วงจรพลังงาน) โชว์ตัวเลขสเปกเป็นหน้าปัด (เช่น ความจุ 5 · ชาร์จ +1)
- ซื้อ = ประกายไฟจากทั่ง + เสียงตอกเหล็ก (ขอเลือกเสียงก่อนโหลด)

### 2.3 พ่อค้าเร่ — "พรมหน้าเกวียน"
- ฉากหลัง: เกวียนผ้าใบม่วง-ทอง · ของวางบนพรมลายเป็น **การ์ดคว่ำ** แล้วพลิกเปิดทีละใบตอนเปิดร้าน
- ตัวนับ "เหลือ N เทิร์น" เป็นนาฬิกาทรายใหญ่มุมจอ (พ่อค้าเร่อยู่สั้น)
- ซื้อ = การ์ดลอยขึ้นแตกเป็นประกายทอง · หมดทั้งร้าน = เกวียนเก็บของ ปิดผ้าใบ

### 2.4 บนกระดาน
- **ร้านกิน 2×2 ช่อง (ผู้ใช้สั่ง 2026-11-08 — เดิม 1×1 เล็กเกิน)** ทุกร้าน · ยืนติดช่องไหนของร้านก็ซื้อได้ (ระยะ 1 จากขอบร้าน แบบตัวใหญ่ `Board.boxOf`)
- จุดร้านค้า (`shopSpots`) = มุมบนซ้ายของร้าน · ต้องเป็นพื้นธรรมดาว่างครบ 4 ช่อง และไม่ทับจุดเกิด/จุดฟื้นฟู → ต้องตรวจ/ย้ายจุดในแผนที่เดิมทุกแผนที่ (Origin 7 ภูมิภาค + Fodlan 5 + Colony)
- ร้าน 3 ร้านพร้อมกัน = กินพื้น 12 ช่อง — (เสนอ) จุดร้านต้องห่างกันอย่างน้อย 1 ช่อง ไม่ให้ปิดทางเดิน
- หมากร้าน 3 แบบ: แผงยาหลังคาผ้า · ชั้นวางเครื่องมือ · เกวียน (เกวียนมีควันฝุ่นตอนโผล่)
- แบนเนอร์ตอนปรากฏ: ShopHerald เดิมแยกสี/ชื่อตามร้าน · "ปรากฏ"
- ปุ่ม HUD ตอนยืนติดร้าน: ปุ่มชื่อร้านนั้น (ยืนติด 2 ร้านพร้อมกัน = 2 ปุ่ม)

## 3. กติการ่วม
- ซื้อได้เมื่อยืนติดร้าน (ระยะ 1) ในตาตัวเอง · เปิดดู/ซื้อแล้วเดินต่อไม่ได้ (เดิม)
- ❓ **ขายคืน** ครึ่งราคา (ปัดลง) ที่ร้านไหนก็ได้ — แท็บ "ขาย" ในทุกร้าน
- ร้านถูกพัง (ท่าเรียวกิ / อรชุน): พังเฉพาะร้านที่โดน ร้านอื่นยังอยู่
- Colony: แคปซูลเสบียงยังเป็นร้านเดียว (ขายของรวม) — ไม่แบ่ง
- การเดินทาง: ทุ่งดอกไม้กลางคืน +2 ต่อช่อง / คลื่นวงวนน้ำกลางวัน ของราคา < 5 ปิดขาย — ใช้กับทุกร้าน (เสนอ)
- ห่วงเวลาซีโร่: ร้านทุกร้านปิด (เดิม)

## 4. งานเบื้องหลัง (server)
- `match.shopPos` / `shopItems` / `shopOpenedRound` / `shopRazed` → `match.shops = [{ id, kind, pos, size: 2, items, openedRound, razed, leaves }]`
- ร้าน 2×2: ใช้แบบเดียวกับตัวละครตัวใหญ่ (`Board.boxOf` / ระยะจากขอบ) — กีดขวาง 4 ช่อง · `nearShop` = ระยะ 1 จากกรอบร้าน · ท่าพังร้านโดนช่องไหนก็พัง · ถอย/ไถลชนร้านนับทุกช่อง · ตัวใหญ่ (Echo/ร่างใหญ่ของไรโด) วางทับร้านไม่ได้
- จุดที่ต้องแก้ (เช็คช่องร้าน = ทุกร้าน): `server/phases/action.js boardBlocked` · `view.js` (ส่ง `shops[]`) · `colony.js` · `moonCell.js` · `whistle.js` · `ice.js` · `flora.js` · `zeroTime.js` · `fodlan/stage2.js` · `fodlan/stage4.js` · `characters/arjuna.js` · `ryougi.js` · `celine.js` · `diego_alt.js` · `kate_emiliko.js` · `engine.js` (`shopPos` → `shopAt(x, y)` / `shops`)
- client: `boardDraw.js` / `BoardStage.jsx` / `BoardCanvas.jsx` / `boardRules.js` (ช่องร้านกีดขวางหลายช่อง) · `Game.jsx` (ปุ่มร้านตามร้านที่ยืนติด)
- socket `viewShop {shopId}` / `buyShopItem {shopId, itemId}` / `sellItem {shopId, uid}` (ถ้าเอาขายคืน)

## 5. ลำดับงาน
1. ต้นแบบหน้าตา 3 ร้านเป็น HTML ใน `.claude/plans/` ให้ผู้ใช้กดดู → ปรับจนผ่าน
2. server: `match.shops[]` ขนาด 2×2 + แก้ทุกจุดเช็คช่องร้าน + ตรวจ/ย้ายจุดร้านในแผนที่ทุกแผนที่ (พฤติกรรมเดิม = ร้านไอเทมร้านเดียว) + เทสต์
3. แบ่งของ 3 ร้าน + ร้านอุปกรณ์ปรากฏพร้อมกัน + พ่อค้าเร่สุ่มโผล่ + เทสต์
4. หมากร้าน 3 แบบบนกระดาน + แบนเนอร์แยกร้าน + ปุ่ม HUD
5. หน้าร้าน 3 แบบตามต้นแบบที่ผ่าน
6. (ถ้าเอา) ขายคืน · เอกสาร GAME_SYSTEM / GRID_PLAN / STATUS_GUIDE
