## 1. state ที่ client ได้
- `players[].ryougi` (เฉพาะตัวเรียวกิ) = `{ eyesCd, mendCd, ultCd, eyes, mind, bloom }`
  - `*Cd` = เทิร์นคูลดาวน์ที่เหลือ (0 = พร้อม) · `eyes` = เทิร์นที่เหลือของเนตรมณะ (สถานะ `netramana`) · `mind` = รากฐานจิต (`ryougiMind`) · `bloom` = บัฟหลังท่าไม้ตาย (`ryougiBloom`)
- `players[].ryougiSlain` = true → คนนี้ถูกเรียวกิสังหารทันที — ถ้าศพค้างบนกระดาน (`corpse`) ให้วาดเป็นกองเลือดแทนร่าง
- `board.terrain["x,y"] === "chasm"` = **ช่องพัง** (เดิน/ยืนไม่ได้ · อยู่จนเปลี่ยนภูมิภาค) — วาดเป็นหลุมดำขอบหยัก ก้นหลุมเรืองแดงจาง · ช่องติดกันต่อขอบเนียน (แนวตัดกันเป็นรูป +) · `board.heal` ไม่มีช่องพังแล้ว
- `board.ryougi.blood` = `[{ x, y, size, id }]` กองเลือด (ภาพเฉย ไม่ขวาง · อยู่จนเปลี่ยนภูมิภาค) — ไม่มีคีย์ `ryougi` = ไม่มีกองเลือด

## 5. ตัดผลสกิล (`server/sever.js`)
ฮุคตัวละคร `severables(engine, p)` → `[{ key, label, at, cancel() }]` — ผลสกิลของตัวเองที่ทำงานอยู่ตอนนี้
- `at` = ลำดับตอนได้ผลนั้นมา (จด `engine.severStamp()` ตอนเปิดผล · ใหม่กว่า = เลขมากกว่า)
- `cancel()` = ปิดผลทันที แบบเดียวกับหมดเวลาเอง: กลับร่างเดิม · ล้างสถานะ · ยกเลิกท่าที่รอ trigger · **สกิลนั้นเข้าคูลดาวน์ตามปกติ**
- `label` = ชื่อที่ผู้เล่นเห็น
